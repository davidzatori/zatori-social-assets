# zatori-social-assets

Öffentliche Bildablage und Werkzeuge für den ZATORI Social Autopilot (Instagram @zatoriai).

- `posts/<datum>-<slug>/01.jpg …` – veröffentlichte Karussell-Slides (Instagram holt sie per Raw-URL)
- `posts/log.json` – Protokoll aller Veröffentlichungen
- `content/pool.md` – Materialpool: Serien, Hooks, Fakten mit Quellen, Regeln
- `tools/make_carousel.py` – erzeugt Slides aus einer JSON-Spezifikation
- `tools/publish_carousel.py` – veröffentlicht einen Slide-Ordner als Karussell

Bilder in diesem Repo sind öffentlich, weil sie ohnehin auf Instagram erscheinen. Hier liegen keine Zugangsdaten.
